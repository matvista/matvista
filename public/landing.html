A worked example

Computed, not drawn to look right.

Take a plain carbon steel and cool it slowly to just below the eutectoid at 727 °C. The diagram beside this is the app’s own Fe–Fe₃C construction; the bars underneath are what the lever rule gives on that tie line, from the same function the module calls — and they move.

Slide past 0.76 wt% C and the constituent that separates out before the reaction changes from ferrite to cementite — same diagram, same lever rule, opposite answer. Then watch where the two colours meet. The boundary falls at the same place in both bars, at every composition, because pearlite is itself 88.9 % ferrite and that ferrite counts toward the total. Microconstituent fractions and phase fractions are different questions; the bars answer both, and show why the answers are not the same number.

Where two modules meet

The same reflection, from both ends.

The Miller module turns a plane into a d-spacing. The XRD module turns a d-spacing into the angle a peak appears at. They are different pages built from different files, so the only honest way to claim they agree is to make the claim checkable. A test takes every reflection the XRD page offers as a link, opens the Miller page it leads to, and fails if the two disagree about whether that reflection is allowed or about the angle it appears at — across five samples and four anodes. It found them disagreeing once, which is why it exists.

1

(111) in copper, a = 0.3615 nm

Miller reduces the indices, takes the reciprocal, and gets d = 0.2087 nm.

d₁₁₁ = a / √(1² + 1² + 1²) = 0.3615 / √3  →  d = 0.2087 nm
2

Bragg, on a copper anode at λ = 0.15406 nm

XRD puts that spacing at 2θ = 43.32° — the first line of the pattern in Fig. 6, and the number the Miller page prints too. The literature says 43.3°; this says what the model computes, which is the difference between quoting and calculating.

θ = arcsin(λ / 2d) = arcsin(0.15406 / 0.4174) = 21.66°  →  2θ = 43.32°
3

And (100), which is not there at all

It has a d-spacing — 0.3615 nm — and Bragg’s law solves for it perfectly well, at 24.61°. It is absent because the structure factor of an FCC lattice vanishes for mixed indices, not because there was nowhere to put it. Both modules say so, and say it the same way.

F₁₀₀ = f[1 + e^(iπ) + e^(iπ) + 1] = 0  →  EXTINCT (Forbidden Peak)

Not every alloy has a fatigue limit

Steel and titanium flatten out: below a certain amplitude — 190 MPa for this 1020 — they survive indefinitely. Nickel has no such limit, and its curve keeps falling until it crosses under the steel it started above. For an alloy like that, “infinite life” is a decision about a number of cycles rather than a property you can lean on.

Choosing a material is choosing a slope

Stiffness against density for 54 materials, log on both axes. A performance index is a straight line on this chart, and moving it sweeps out the candidates that beat a given value — which is why the answer for a light stiff beam is not the same as for a light stiff tie.

The missing peaks are the information

Copper, indexed. Every reflection on this plate is all-odd or all-even, and that is the whole identification: in an FCC crystal the structure factor extinguishes the mixed indices, so (100) and (110) are not weak here, they are absent. Switch the sample in the module and a different set goes missing.

How the numbers are made

Four commitments the modules keep.

A teaching tool earns its place by being honest about what it knows, and about where the knowing stops.

01

Data and interpolation are kept apart

Fixed points — invariant reactions, solubility limits, tabulated radii and moduli — are cited to Callister & Rethwisch. The curves between them are constructed, and every module says which is which rather than implying a precision it does not have.

02

Approximations say so

Laying a continuous cooling path over an isothermal diagram is a textbook construction, not a measurement, so the heat-treatment module tells you that and explains which way the answer leans.

03

Surprises get explained, not hidden

When 1080 shows M90 below room temperature, that is retained austenite, and the module says so — a result worth understanding rather than a number worth suppressing.

04

Every view has a link

A specific plane, steel or cooling rate lives in the URL, so a worked example can be handed to a class as a link and it opens exactly as you left it.

Who it is for

Three ways people use it.

Students

Work the geometry until it is obvious. Type indices and see the plane; move the composition and watch the lever rule do what the textbook says it does.

Instructors

Set up a case, copy the address bar, paste it into a worksheet. The link carries the state, so everyone opens the same diagram.

Engineers

A quick reference for the relations you half-remember — d-spacing, Schmid factors, hardenability, performance indices — with the working shown.
